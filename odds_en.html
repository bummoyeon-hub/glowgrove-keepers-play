Stat lines and value ranges

Lines = 1 main line + sub lines: Common / Uncommon 1, Rare / Epic 2, Legendary / Mythic / Immortal 3. The main stat depends on the slot (Weapon ATK, Helmet HP, Armor DEF, Gloves ATK, Boots HP, Necklace HP, Ring ATK, Lantern ATK).

Main value = the base value of the item level × the rarity multiplier × 90–110% (uniform). Rarity multipliers: Common ×1.0, Uncommon ×1.6, Rare ×2.6, Epic ×4.2, Legendary ×7.0, Mythic ×12.0, Immortal ×20.0.

Guardian Summon

Price: 1 pull = 150 moonstones, 10 pulls = 1,500 moonstones (10 × the single price, no discount). Summon tickets are used first (1 ticket = 1 pull). A 10-pull has NO extra guarantee: each of the 10 results uses the odds below (each pull counts toward the pity).

Pity: after 89 pulls without a join, the 90th pull is a guardian join. Any join (pity or not) resets the counter to 0. This counter is separate from the Limited Pickup pity.

Limited Pickup

Price: 1 pull = 150 moonstones, 10 pulls = 1,500 moonstones (10 × the single price, no discount). Summon tickets are used first (1 ticket = 1 pull). A 10-pull has NO extra guarantee: each of the 10 results uses the odds below (each pull counts toward the pity).

Pity (all pickup banners): if you pull 79 times without a limited result (the limited guardian or the exclusive weapon), the next result is the limited target you chose (guardian or weapon). The counter goes up by 1 for each pickup pull that is not a limited result and returns to 0 whenever a limited result appears (pity or not). It does NOT reset when a banner ends: it carries over to the next Limited Pickup. It is separate from the Guardian Summon counter.

Reruns: a limited guardian returns at the earliest 120 days (4 months) after its banner ended. There is no reward that requires collecting a set of different results.

General rules

  • Odds are the game data's weights (10,000 = 100%) shown to two decimals. There are no hidden adjustments.
  • Results come from a random sequence stored per account: retrying or restarting the game does not change them.
  • Banner status (Running / Ended / Upcoming) is as of the publication date. When odds change, the in-game sheets and this page change together from the same data and the version changes.
  • Odds are identical whether a pull uses summon / pickup tickets or moonstones: the same odds tables apply.
